# Клиент

Веб-клиент — одностраничное приложение на React 19, TypeScript и Vite, стили на Tailwind CSS 4 с дизайн-токенами для светлой и тёмной тем. Подробная структура каталога `frontend/src` и сценарии запуска — в `frontend/README.md`; здесь описаны решения, которые влияют на путь пользователя.

## Гость и возврат после входа

Каркас приложения (`AppShell` в `App.tsx`) решает, что показывать, по двум признакам: есть ли вошедший пользователь и есть ли сохранённый токен.

| Состояние | Что происходит |
|-----------|----------------|
| Проверяется сохранённый токен | Экран загрузки. Если сервер отвечает дольше 4 секунд, добавляется пояснение «Сервер отвечает дольше обычного» — вместо пустого экрана |
| Гость, адрес `/welcome` или `/auth` | Приветственная страница или вход |
| Гость, любой другой адрес | Перенаправление на `/welcome?next=<адрес>`; после входа или регистрации человек попадает туда, куда шёл (например, на мероприятие по ссылке друга) |
| Вошедший пользователь на `/welcome` | Перенаправление на главную |
| Токен есть, но сервер недоступен | Пользователь остаётся в приложении (офлайн-режим); выход происходит только после ответа сервера `401` |

Адрес возврата проходит `safeNext` (`utils/redirect.ts`): принимаются только внутренние пути, начинающиеся с одного `/`; `//evil.com`, `https://…` и адреса самой приветственной страницы и входа отбрасываются, иначе `?next=` стал бы открытым перенаправлением.

**Приветственная страница** (`LandingPage`) показывает цифры из публичного `GET /public/stats` (предстоящие мероприятия, участники, виды спорта, организации) и ближайшие встречи. Без ответа сервера она остаётся рабочей — просто без цифр. Картинки лежат в `public/landing/` в двух размерах (версия `-m` для телефона, выбор — через `srcset`); nginx отдаёт их с кэшем на неделю и сжимает текстовые ответы gzip, поэтому первая загрузка на телефоне быстрая.

## Обучающий тур

`OnboardingTour` подсвечивает реальные элементы интерфейса (атрибуты `data-tour`, для нижней панели телефона есть отдельные варианты `-mobile`) и ведёт по шагам: рекомендации, карта и лента, фильтры и радиус, поиск и город, создание событий и билеты. Последний шаг приглашает пройти тест интересов. Положение подсказки подбирается под ширину экрана: на телефоне карточка компактная и занимает ширину экрана.

Тур запускается:

- после регистрации пользователя (флаг в `sessionStorage`);
- при первом входе пользователя с ролью `ROLE_USER` на главной — отметка о прохождении хранится в `localStorage` отдельно для каждого аккаунта;
- по ссылке `/?tour=1`;
- кнопкой «Обучение по сайту» в собственном профиле.

Тур можно пропустить в любой момент.

## Тест интересов

`InterestQuiz` («Компас интересов») состоит из шести шагов: год рождения, тип досуга, удобное время, виды спорта, уровень и город с расстоянием. Результат сохраняется одним `PUT /me/preferences`. Если справочники видов спорта и городов не загрузились, шаг показывает ошибку с кнопкой «Повторить» и блокирует «Дальше». Как ответы влияют на подборку — в разделе [Рекомендательная система](recommendations.md#интересы).

## Сканер билетов

`CheckInScannerModal` открывается на весь экран порталом в `document.body`. Контейнер видоискателя показывается до запуска камеры (иначе видео получает нулевую ширину), поверх камеры цвета заданы явно, потому что в тёмной теме токен белого цвета инвертируется. Подробности про HTTPS, ошибки камеры, фонарик и защиту от повторных сканов — в [Архитектуре](architecture.md#билеты-и-отметка-на-входе).

## Поведение при сбоях сети

- У всех запросов таймаут 20 секунд, у проверки входа при старте — 8. Сообщение об ошибке различает «нет связи с сервером» и «сервер слишком долго не отвечает».
- Страницы, которые не смогли загрузить данные (главная, «Для вас», «Мои события», «Уведомления», карточка мероприятия), показывают сообщение с кнопкой «Повторить» (`ErrorNotice` в `components/ui.tsx`), а не тупик.
- Отмена участия, отзыв заявки и выход из очереди требуют подтверждения (`CancelParticipationDialog` в «Моих событиях», такой же диалог на странице мероприятия).
- В форме входа и регистрации пароль можно показать кнопкой с глазом.
