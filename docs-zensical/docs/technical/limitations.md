# Ограничения и развитие

## Не реализовано

- Push-уведомления.
- Офлайн и установка PWA на сервере с самоподписанным сертификатом: браузер не регистрирует service worker, пока сертификат не доверенный. См. [PWA](pwa.md).
- Уведомления об ответах в обсуждении.
- Сбор интересов при регистрации: после регистрации запускается обучающий тур, который предлагает пройти тест интересов; также их можно указать в профиле или на странице рекомендаций.
- Напоминания, кроме одного за сутки до начала, и другие каналы (push, e-mail).
- Расписание повторяющихся мероприятий наперёд и перенос участников на следующее занятие: следующее занятие создаётся только при завершении текущего.
- «Поделиться геопозицией»: в конфигурации есть флаг `features.location-sharing.enabled`, кода под ним пока нет.
- Сквозные браузерные тесты и интеграционные тесты с реальной базой.

## Известные упрощения

| Что | Как сейчас | Что менять при росте нагрузки |
|-----|------------|-------------------------------|
| CORS | Открыт для всех источников (для демо) | Ограничить список источников |
| Загрузки | Лежат на диске (volume) | Объектное хранилище при нескольких экземплярах бэкенда |
| Кэш рекомендаций | Локален процессу | Redis через интерфейс `RecommendationCache` |
| Обсуждение | Опрос раз в 8 секунд | SSE или WebSocket |
| Уведомления | Опрос раз в 20 секунд | SSE или WebSocket; push |
| Счётчики мест на карте | Могут отставать до 60 секунд (TTL кэша карты) | Сбрасывать кэш при изменении участия или обновлять счётчики поверх кэша |
| Достижения | Считаются SQL-запросами при каждом обращении; клиент опрашивает раз в 15 секунд | Предрасчёт и событийная модель |
| Похожие виды спорта | Порог поддержки мал из-за демо-данных | На реальном трафике поднять `similarity-min-cooccurrence` |
| Ключ 2GIS | Встраивается при сборке фронтенда | Серверный прокси или ограничение ключа по домену |

## Направления развития

- Обученная модель ранжирования (LTR) на журнале показов `recommendation_log`.
- Отдельный полнотекстовый поиск на всю страну.
- Выделение рекомендаций в сервис при росте нагрузки.
- Уведомления и реальное время для обсуждений и заявок.
- Мобильное приложение поверх существующего REST API.
