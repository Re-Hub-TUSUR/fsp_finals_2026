# PWA

Sportikus устанавливается на главный экран телефона и компьютера как приложение и работает без сети: открывается оболочка, а в «Моих событиях» доступны билеты с QR-кодами.

## Из чего состоит

| Часть | Файл | Что делает |
|-------|------|------------|
| Манифест | `frontend/public/manifest.webmanifest` | Название, иконки (обычные и maskable), цвета, режим `standalone`, ярлыки «Мои события», «Для вас», «Создать» |
| Иконки | `frontend/public/icons/` | 192 и 512 px, maskable-варианты с буквой в безопасной зоне, `apple-touch-icon` для iPhone |
| Service worker | `frontend/public/sw.js` | Кэш оболочки и личных данных для офлайна |
| Регистрация | `frontend/src/pwa.ts` | Регистрирует `/sw.js` только в собранной версии (в `npm run dev` не мешает горячей перезагрузке) |
| Интерфейс | `frontend/src/components/PwaBanners.tsx` | Баннер установки и плашка «Нет сети» |

## Что кэширует service worker

| Запрос | Стратегия | Зачем |
|--------|-----------|-------|
| Страницы приложения | Сначала сеть, без сети — последняя сохранённая копия `index.html` | Новая версия приходит сразу, без сети приложение всё равно открывается |
| `/assets/*` | Сначала кэш | Файлы сборки с хэшем в имени не меняются |
| Иконки, манифест, логотип | Отдать из кэша и обновить в фоне | Быстрый старт |
| `/api/v1/me/participations`, `/me/events`, `/auth/me`, `/me/preferences` | Сначала сеть, без сети — сохранённый ответ | Билеты и «Мои события» на входе без интернета |
| Остальной API | Только сеть | Каталог, места и заявки должны быть свежими |

Если сохранённого ответа нет, API отвечает `503` с `{"error": {"code": "OFFLINE", ...}}` — интерфейс показывает понятное сообщение. Страницы бэкенда (`/uploads`, `/swagger-ui`, `/v3/api-docs`, `/actuator`) service worker не трогает.

QR-код билета рисуется на устройстве из кода билета, поэтому показать билет на входе можно без интернета, если «Мои события» открывались хотя бы раз с сетью.

## Личные данные

Сохранённые ответы личного кабинета удаляются при выходе из аккаунта, входе и смене демо-роли — офлайн-копии прежнего пользователя не остаются на устройстве. При ответе `401` сохранённая копия тоже удаляется.

Без сети приложение больше не выходит из аккаунта при старте: токен сбрасывается только если сервер явно ответил `401`.

## Установка

- **Android, Chrome и Edge на компьютере.** Внизу появляется баннер «Установите Sportikus» с кнопкой «Установить» — она открывает системный диалог.
- **iPhone и iPad.** Системного диалога нет, баннер подсказывает: «Поделиться» → «На экран „Домой“».
- Баннер не показывается в уже установленном приложении и две недели после «Не сейчас».

## Требование к сертификату

Service worker регистрируется только на странице с **доверенным** HTTPS-сертификатом (или на `localhost`). На самоподписанном сертификате камера работает после «Всё равно перейти», но service worker браузер не регистрирует. В этом случае нет офлайна, а на Android вместо установленного приложения получается обычный ярлык. Манифест, иконки и ярлык на главном экране при этом работают.

Бесплатные способы получить доверенный сертификат:

- **Домен и Let's Encrypt** — штатный путь для продакшена.
- **sslip.io или nip.io без покупки домена.** Имя вида `109-196-167-212.sslip.io` указывает на IP сервера, и Let's Encrypt выдаёт на него сертификат (например, через `certbot`).

## Как проверить

1. Соберите фронтенд: `npm run build`, затем `npm run preview` — на `http://localhost:4173` service worker работает без HTTPS.
2. В DevTools → Application: в Manifest нет ошибок, в Service workers статус `activated`.
3. Откройте «Мои события» под демо-аккаунтом, выключите сеть (DevTools → Network → Offline) и обновите страницу — приложение и билеты на месте, сверху плашка «Нет сети».

## Обновление

При изменении стратегии кэширования увеличьте `VERSION` в `sw.js`: при активации новой версии старые кэши удаляются. Обычные релизы версию менять не требуют — страница всегда сначала берётся из сети.
