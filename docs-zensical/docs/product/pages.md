# Карта страниц

Веб-клиент — одностраничное приложение (React Router). Маршруты заданы в `frontend/src/App.tsx`. Незнакомый путь перенаправляет на главную.

| Маршрут | Экран | Доступ | Главное действие |
|---------|-------|--------|------------------|
| `/`, `/events` | Главная: карта 2GIS и каталог | все | Найти мероприятие, открыть карточку, записаться |
| `/events/new` | Конструктор мероприятия | вход; организация — только одобренная | Опубликовать мероприятие |
| `/events/:id` | Карточка мероприятия | все | Записаться или подать заявку; обсудить; показать QR-билет; завершить (организатор) |
| `/events/:id/manage` | Управление заявками | организатор мероприятия | Принять или отклонить заявку, исключить участника, сканировать билеты на входе |
| `/my` | Личный кабинет | вход | «Я участвую», «Я организую», «Архив»; показать билет |
| `/recommended` | Рекомендации «Для вас» | вход | Открыть подходящее мероприятие, «Не интересно», задать интересы |
| `/profile` | Собственный профиль | вход | Править профиль и фото, интересы, друзья, подписки, достижения |
| `/profiles/:type/:id` | Публичный профиль пользователя или организации | все (профиль неодобренной организации — владелец и админ) | Добавить в друзья, подписаться, посмотреть мероприятия |
| `/auth` | Вход и регистрация | все | Войти, зарегистрироваться как пользователь или организация |
| `/admin` | Панель администратора | `ROLE_ADMIN` | Организации, мероприятия (в том числе помеченные ⚠), комментарии |

## Сквозные элементы

- **Верхнее меню и нижняя панель на телефоне** — главная, «Для вас», «Создать», «Мои события», профиль.
- **Панель «Демо-режим»** — вход под любым демо-аккаунтом в один клик (настоящий вход по JWT). См. [Акторы и демо-аккаунты](../actors/personas.md).
- **Переключатель темы** — светлая или тёмная, выбор запоминается.
- **Уведомление о достижении** — всплывающая карточка, когда пользователь получает новое достижение.

## Пустые состояния и ошибки

Каждый список показывает понятное пустое состояние («В архиве пока нет завершённых событий», «Вы пока не подписаны ни на одну организацию»). Ошибки API выводятся текстом из поля `error.message`, при отсутствии связи — «Нет связи с сервером». Без ключа 2GIS вместо карты показывается заглушка, остальной интерфейс работает.
