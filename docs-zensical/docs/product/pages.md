# Карта страниц

Веб-клиент — одностраничное приложение (React Router). Маршруты заданы в `frontend/src/App.tsx`. Гость видит только `/welcome` и `/auth`: любой другой адрес ведёт его на `/welcome?next=…`, и после входа он возвращается туда, куда шёл. Незнакомый путь перенаправляет на главную.

| Маршрут | Экран | Доступ | Главное действие |
|---------|-------|--------|------------------|
| `/welcome` | Приветственная страница | гость (вошедшего перенаправляет на `/`) | Увидеть цифры платформы и ближайшие встречи, войти или зарегистрироваться |
| `/`, `/events` | Главная: карта 2GIS и каталог | вход | Найти мероприятие, открыть карточку, записаться; при первом входе — обучающий тур |
| `/events/new` | Конструктор мероприятия | вход; организация — только одобренная | Опубликовать мероприятие |
| `/events/:id` | Карточка мероприятия | вход (гость по ссылке попадает на `/welcome` и после входа возвращается сюда) | Записаться, подать заявку или встать в очередь; обсудить; позвать друзей; показать QR-билет; завершить (организатор) |
| `/events/:id/manage` | Управление заявками | организатор мероприятия | Принять или отклонить заявку, исключить участника, сканировать билеты на входе, выгрузить участников в CSV |
| `/my` | Личный кабинет | вход | «Я участвую», «Я организую», «Архив»; показать билет; отменить участие с подтверждением |
| `/recommended` | Рекомендации «Для вас» | вход | Открыть подходящее мероприятие, «Не интересно», пройти тест интересов |
| `/notifications` | Уведомления | вход | Прочитать, перейти по ссылке, отметить прочитанными |
| `/profile` | Собственный профиль | вход | Править профиль и фото, интересы и тест, обучение по сайту, друзья, подписки, достижения |
| `/profiles/:type/:id` | Публичный профиль пользователя или организации | все (профиль неодобренной организации — владелец и админ) | Добавить в друзья, подписаться, посмотреть мероприятия |
| `/auth` | Вход и регистрация | все | Войти, зарегистрироваться как пользователь или организация, показать пароль |
| `/admin` | Панель администратора | `ROLE_ADMIN` | Организации, мероприятия (в том числе помеченные ⚠), комментарии |

## Сквозные элементы

- **Верхнее меню и нижняя панель на телефоне** — главная (карта и лента), «Для вас», «Создать», «Мои события», профиль; колокольчик уведомлений в шапке.
- **Обучающий тур** — подсвечивает элементы интерфейса; запускается при первом входе, повторяется кнопкой «Обучение по сайту» в профиле.
- **Панель «Демо-режим»** — вход под любым демо-аккаунтом в один клик (настоящий вход по JWT). См. [Акторы и демо-аккаунты](../actors/personas.md).
- **Переключатель темы** — светлая или тёмная, выбор запоминается.
- **Уведомление о достижении** — всплывающая карточка, когда пользователь получает новое достижение.

## Пустые состояния и ошибки

Каждый список показывает понятное пустое состояние («В архиве пока нет завершённых событий», «Вы пока не подписаны ни на одну организацию»). Ошибки API выводятся текстом из поля `error.message`, при отсутствии связи — «Нет связи с сервером», а если сервер не отвечает слишком долго — «Сервер слишком долго не отвечает». Страница, не загрузившая данные, показывает кнопку «Повторить». При старте приложения вместо пустого экрана показывается загрузка с пояснением. Без ключа 2GIS вместо карты показывается заглушка, остальной интерфейс работает.
