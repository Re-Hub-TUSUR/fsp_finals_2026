# Обзор продукта

**Sportikus** помогает найти и организовать спортивное (и не только) мероприятие рядом с собой. Платформа не привязана к одному городу: каталог, геопоиск и рекомендации рассчитаны на масштаб страны.

## Для кого

| Аудитория | Что получает |
|-----------|--------------|
| Любитель спорта | Карту и каталог мероприятий рядом, понятные условия, запись в пару кликов, персональные рекомендации с объяснением причин |
| Организатор-частное лицо | Конструктор мероприятия, контроль над заявками, обсуждение под событием, электронные билеты и отметку участников на входе |
| Организация (клуб, секция, федерация) | Публикацию без премодерации после одобрения, блок сведений об организаторе, подписчиков, профиль с логотипом |
| Администратор площадки | Одобрение организаций, снятие мероприятий с публикации, скрытие комментариев, разбор помеченных автопроверкой мероприятий |

## Возможности

| Область | Что умеет платформа |
|---------|---------------------|
| Знакомство | Приветственная страница для гостя с живыми цифрами платформы; обучающий тур по сайту для нового пользователя (в вебе и на телефоне) и тест интересов в конце |
| Карта и каталог | Карта 2GIS с метками (время до старта, свободные места), список, поиск, фильтры по виду спорта, уровню, режиму записи, времени, расстоянию, цене. Каталог загружается для видимой области карты |
| Конструктор мероприятий | Готовые шаблоны с настраиваемыми полями, свой вид спорта, свои параметры, анкета участника; для организаций — блок сведений организатора; повторение занятия с интервалом 1–365 дней |
| Мероприятия от пользователя и организации | Пользователь публикует от своего имени, организация — от имени организации после одобрения администратором |
| Участие с подтверждением | Режимы «по заявке» и «свободный вход», отмена с подтверждением, исключение, лимит мест под блокировкой; очередь на места: освободившееся место получает первый откликнувшийся |
| Электронные билеты | У подтверждённого участника — уникальный QR-билет (доступен и без сети); организатор сканирует его камерой на весь экран с фонариком, по фото или вводит код вручную, видит счётчик отмеченных |
| Обсуждение под событием | Вопросы участников и ответы организатора со значком «Организатор», автообновление, мягкое скрытие сообщений |
| Рекомендации | Раздел «Для вас»: подборка по интересам, возрасту, уровню, месту, времени и истории с причинами и кнопкой «Не интересно»; интересы за минуту собирает тест «Компас интересов» |
| Социальные функции | Друзья (заявки, поиск по e-mail, «Идут друзья» на карточке), приглашение друзей на мероприятие, подписки на организации, достижения за активность |
| Уведомления | Колокольчик и страница уведомлений: решения организатора, приглашения, заявки в друзья, освободившиеся места из очереди, напоминание за сутки до начала |
| Архив и повторы | Организатор завершает прошедшее мероприятие — оно уходит в архив организатора и участников; у повторяющегося сразу появляется следующее занятие. Список участников выгружается в CSV |
| Автопроверка | Фильтр запрещённых тем и проверка ИИ за несколько секунд после создания; сомнительное помечается ⚠ для администратора |
| Модерация | Организации, мероприятия, комментарии; фильтры «Требуют внимания» и «Отклонены автопроверкой» |
| Вся страна | Геопоиск PostGIS, 44 города со справочником часовых поясов, время показывается по местному времени площадки |
| Интерфейс | Светлая и тёмная темы, адаптивная вёрстка с нижней навигацией на телефоне, экспорт события в календарь (`.ics`); при сбое сети — сообщение с кнопкой «Повторить» |
| PWA | Установка на главный экран, офлайн-оболочка и билеты без сети (нужен доверенный HTTPS) |

## Принципы

- **API-first.** Вся логика и проверка прав — на бэкенде, веб-клиент лишь один из потребителей REST API.
- **Данные вместо кода.** Формат мероприятия задаётся JSON-схемой в таблице `event_templates`: новый вид активности — строка в БД, а не релиз.
- **Объяснимость.** Рекомендация приходит с причинами и вкладом каждого признака.
- **Предсказуемые ошибки.** Единый формат `{"error": {"code", "message"}}` и осмысленные HTTP-статусы.
