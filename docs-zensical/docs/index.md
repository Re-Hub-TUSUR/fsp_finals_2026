## Платформа в двух словах

Пользователь находит мероприятие на карте 2GIS или в каталоге, записывается сразу или по заявке — и получает электронный QR-билет. Организатор (человек или одобренная организация) собирает мероприятие в конструкторе из готовых шаблонов, принимает заявки, отвечает на вопросы в обсуждении и отмечает участников на входе. Администратор модерирует организации, мероприятия и комментарии, а новые мероприятия ещё до этого проходит автопроверка: фильтр запрещённых тем и, при сомнении, проверка ИИ.

Рекомендации на странице «Для вас» строятся на PostgreSQL + PostGIS, каждая карточка объясняет, почему она показана.

## Быстрый старт

```bash
docker compose up --build -d
```

Веб-приложение — `http://localhost:3000`, Swagger UI — `http://localhost:8080/swagger-ui/index.html`. Подробности: [Локальный запуск](technical/local-start.md).
