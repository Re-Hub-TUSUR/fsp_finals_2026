# Глоссарий

| Термин | Значение |
|--------|----------|
| Мероприятие (событие) | Спортивная или иная активность с местом, временем, вместимостью и режимом записи |
| Шаблон | Готовый формат мероприятия: поля, вопросы участнику и значения по умолчанию, описанные данными в таблице `event_templates` |
| Конструктор | Форма создания мероприятия, собранная из шаблона, видов спорта, своих параметров и анкеты |
| Анкета участника | Вопросы организатора к подающему заявку (`registration_fields`) |
| Режим записи | `OPEN` — запись подтверждается сразу; `APPROVAL` — по заявке с решением организатора |
| Заявка | Участие в статусе `PENDING`, ожидающее решения организатора |
| Участие | Связь пользователя с мероприятием; статусы `PENDING`, `CONFIRMED`, `REJECTED`, `CANCELLED` |
| Билет | Уникальный код участия `SPT-XXXXXXXX`, отображаемый QR-кодом |
| Отметка на входе (check-in) | Подтверждение организатором, что билет предъявлен и использован |
| Организатор | Автор мероприятия или владелец организации, от имени которой оно опубликовано |
| Организация | Юридическое лицо с реквизитами (ИНН, ОГРН, КПП); публикует после одобрения администратором |
| Автопроверка | Фильтр запрещённых тем и при сомнении проверка ИИ при создании мероприятия |
| Пометка ⚠ | Знак для администратора: мероприятие опубликовано, но требует внимания |
| Мягкое скрытие | Сообщение остаётся в базе, обычным пользователям показывается заглушка |
| Архив | Статус `ARCHIVED`: завершённое организатором мероприятие |
| Рекомендация | Мероприятие в выдаче «Для вас» с причинами и вкладом признаков |
| Источник кандидатов | Способ выбрать мероприятия для ранжирования: `INTEREST`, `POPULAR`, `ORGANIZER`, `SOON` |
| Накопленный интерес (affinity) | Вес сущности (вида спорта, организатора, шаблона, времени суток), растущий от действий пользователя и затухающий со временем |
| Холодный старт | Ситуация без интересов и истории: показывается популярное рядом |
| PostGIS | Расширение PostgreSQL для геоданных и пространственных индексов |
| GiST | Тип индекса для геопоиска по близости |
| Кэш карты | Список мероприятий области карты без личных данных, хранится в Redis |
| RouterAI | OpenAI-совместимый шлюз к языковым моделям, через который работает проверка ИИ |
| 2GIS MapGL | JavaScript-библиотека карт 2GIS, используемая клиентом |
| JWT | Токен авторизации; передаётся в заголовке `Authorization: Bearer` |
| Flyway | Инструмент версионирования схемы базы данных |
| Zensical | Генератор статических сайтов документации, на котором собрана эта документация |
