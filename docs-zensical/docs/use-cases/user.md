## Правила участия

- Режим `OPEN` — запись подтверждается сразу; режим `APPROVAL` — решает организатор.
- Нельзя записаться на собственное мероприятие, снятое с публикации, завершённое, с закрытой регистрацией, повторно при активной заявке.
- Если в анкете есть обязательные вопросы, их нужно заполнить; если организатор задал требования (справка, страховка, документы) — подтвердить ознакомление.
- Последнее место нельзя выдать дважды: операции с местами выполняются под блокировкой строки мероприятия.
