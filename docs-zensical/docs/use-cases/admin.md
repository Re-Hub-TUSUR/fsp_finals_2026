# Use cases администратора

Панель администратора — `/admin`. Все методы `/api/v1/admin/**` доступны только `ROLE_ADMIN`.

| ID | Сценарий | Результат |
|----|----------|-----------|
| UC-A-01 | Одобрить организацию | Статус `APPROVED`; организация публикует мероприятия сразу, без премодерации |
| UC-A-02 | Отклонить организацию | Статус `REJECTED` с обязательной причиной, которую видит владелец |
| UC-A-03 | Снять мероприятие с публикации | Статус `UNPUBLISHED` с причиной; исчезает из каталога, карты и рекомендаций; по прямой ссылке видна плашка, запись закрыта |
| UC-A-04 | Вернуть мероприятие | Статус `PUBLISHED`, пометка автопроверки снимается; так исправляется ошибочное отклонение |
| UC-A-05 | Разобрать помеченные автопроверкой мероприятия | Список сортируется так, что `⚠` идут первыми; видны объяснение ИИ, найденные слова и модель; кнопка «Проверено» снимает пометку |
| UC-A-06 | Скрыть комментарий | Мягкое скрытие: обычные пользователи видят «Сообщение скрыто модератором», настоящий текст виден только администратору; вкладка «Комментарии» показывает ленту с названиями мероприятий |
| UC-A-07 | Найти организацию, мероприятие или комментарий | Поиск на каждой вкладке: организации — по названию, владельцу и e-mail, мероприятия — по названию, организатору, виду спорта и городу, комментарии — по тексту, автору и мероприятию; название организации и имя организатора ведут на их страницы с размещёнными мероприятиями |

## Фильтры панели

Мероприятия: «Все», «Требуют внимания» (помечены ⚠), «Отклонены автопроверкой». У вкладки организаций счётчик заявок, ожидающих решения (`PENDING`), показан на самой вкладке.
