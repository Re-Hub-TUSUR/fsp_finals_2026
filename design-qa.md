## Findings

1. [P1] Неодинаковое время одного события.
   Воспроизведение: браузер Europe/Moscow → каталог → поиск «Бачата» → лента → карточка → «Открыть страницу».
   Фактически: лента и панель показывают 15:30, страница /events/15 — 19:30 с подписью «Красноярск (UTC+7)». В рекомендациях карточка одновременно содержит 15:30 и «Сегодня в 19:30».
   Влияние: пользователь может неправильно определить время встречи; около полуночи также возможна ошибка даты.
   Доказательства: 05-search-list.png, 07-event-panel.png, 08-event-desktop.png, 10-recommendations.txt, 24-time-mismatch.png.
   Вероятная область исправления: frontend/src/utils/eventView.ts:140, rowTime, formatCardDate, startLabelLong, timeRange; они используют пояс браузера. Согласовать с event.timeZone и форматом страницы события, подписывать пояс; согласовать календарные фильтры с выбранным правилом.

2. [P2] Мобильная навигация теряет поисковый запрос.
   Воспроизведение: 390x844 → карта → поиск «Бачата» → нижняя вкладка «Лента».
   Фактически: URL /?q=Бачата заменяется на /?view=list, поле пустеет, вместо одного события появляются 16.
   На десктопе тот же переход сохраняет запрос.
   Доказательства: checks.json / final-checks.json, test «mobile view preserves query»; 15-mobile-list.png.
   Область исправления: frontend/src/components/MobileTabBar.tsx:33. Формировать ссылки из текущего URLSearchParams, изменяя только view; сохранять city и q.

3. [P2] Фокус выходит за пределы модального окна фильтров.
   Воспроизведение: открыть «Фильтры» мышью → нажать Tab.
   Фактически: при открытии document.activeElement остаётся на фоновой кнопке «Фильтры»; следующий Tab переводит фокус на фоновую ссылку. В обоих состояниях closest('[role=dialog]') отсутствует.
   Escape закрывает диалог, но начальный фокус и удержание фокуса отсутствуют.
   Доказательства: checks.json, tests «modal initial focus» и «modal tab focus»; 06-filters.png.
   Область исправления: frontend/src/components/Modal.tsx:15. Переводить фокус внутрь, удерживать Tab/Shift+Tab в диалоге, делать фон inert и возвращать фокус на инициатор при закрытии.

4. [P2] Неподходящая обложка велопрогулки.
   Воспроизведение: открыть ленту; первая карточка «Велопрогулка по набережной Енисея».
   Фактически: обложка показывает сетевую стойку с кабелями вместо велоспорта.
   Доказательства: 22-responsive-320.png, 22-responsive-768.png.
   Вероятная область исправления: frontend/src/utils/eventCoverImages.ts:39, SPORT_PHOTOS.velosport. Проверить реальное содержимое назначенных фотографий, заменить неверное фото, предусмотреть fallback при недоступности внешних изображений. Источник custom imageUrl также поддерживается кодом; данные этого поля отдельно не проверялись.

## Сетевые наблюдения

В конце прогона получен HTTP 502 на /api/v1/me/notifications. Постоянный сбой не установлен.
Одна консольная ошибка {status: 0, message: Network error} на /events/new; в сетевом журнале есть ERR_HTTP2_PING_FAILED для тайла 2GIS. Это совпадение не доказывает общую причину.
Отдельная фотография Unsplash photo-1508098682722-e99c43a406b2 неоднократно получила ERR_BLOCKED_BY_ORB. Видимый сломанный плейсхолдер не подтверждён; на проверенных размерах у загруженных видимых изображений naturalWidth > 0.
Предупреждения WebGPU/performance относятся к графическому рантайму карты; ERR_ABORTED тайлов возникают при перемещениях и пересоздании карты. Их не считаю доказательством отказа карты.
Повторные навигации на финальном этапе иногда превышали 6/15 секунд, после чего документ всё же был complete и содержал каталог. Чистую производительность загрузки этот прогон не измеряет.
